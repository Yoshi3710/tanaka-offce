# 株式会社タナカ 帳票作成プロトタイプ（確認用）

社員専用受発注管理システムの構築に先立ち、**発注書／納品書／請求書のレイアウトだけを先行確認**するための静的試作です。

- 発注書：A4横。以前の「注文書変換設計」を参考に、学校直送・メーカー宛先・学校名・学年組・数量・問い合わせTELなどを表示
- 納品書・請求書：A4縦。品番、品名、規格、数量、単価、金額、備考、合計を表示
- 担当営業：太田、会野、藤井、長谷、恩田、社長
- すべて手動修正可。明細の追加・削除、サンプル入力、印刷/PDF保存、手動JSONダウンロード・読み込み
- 軽量化：外部JavaScript/CSSライブラリ不使用。学校向けサイトの正式ロゴをローカル配置
- 試作データの自動送信・自動サーバー保存・ログイン認証・メーカーへの正式発注は**未実装**
- JSONファイルには入力した文字列が含まれます。共用PCで実データを使わないでください

**注意**：GitHub Pagesは公開環境です。実在する学校の個人情報、仕入価格、正式な取引書類などは入力しないでください。正式運用は認証・権限・サーバー保護・監査履歴が必要です。

既存の学校向け販売サイトや注文書変換ツールは変更していません。
