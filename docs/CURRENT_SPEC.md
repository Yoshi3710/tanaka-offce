更新：2026-11-13  
適用対象：GitHub試作の \`index.html\`（帳票）・\`staff.html\`（社員用画面）、将来のXserver本番版  
**このファイルは「現在有効な仕様」の基準です。実装と矛盾するときは、最新のユーザー決定を確認し、勝手に旧仕様へ戻さないでください。**

## 変更の原則

1. **ユーザーの最新の明確な決定が優先**。過去の案、古いREADME、以前のコードより優先する。
2. 指定された箇所以外の画像・文言・色・配置・機能を独断で変えない。副作用が避けられないときは、実装前に相談する。
3. 変更前に対象ファイルと現状を取得して記録し、**変更前後の差分**で意図しない変更がないか検証する。
4. 構文・機能・入力・保存・復元・印刷・スマホ・PC・枠内表示を、変更内容に応じて検査する。未検証事項を「確認済み」と報告しない。
5. 再発する不具合はその場しのぎで積み重ねず、原因と**根本解決案**、リスク、既存仕様への影響を示す。
6. 軽量で安全なコードを維持。学校・取引先・先生・児童生徒の個人情報を最小化。公開試作では**実データの入力・送信・保存を行わない**。
7. 本番環境を無断で変更しない。Xserverでの公開は、ユーザーの承認・バックアップ・検査・復旧手順を経て行う。

## 現時点で変更してはいけないもの

- 仮承認した発注書・納品書・請求書を、別作業に便乗して無断変更しない。
- 指定したタナカのロゴ画像は、使用する箇所に限り**既存の \`assets/logo.webp\`** を利用する。帳票でロゴ不要と決めた箇所には追加しない。
- 公開GitHub Pagesに実際の学校／メーカーの住所録、電話帳、注文データ、認証情報を置かない。
